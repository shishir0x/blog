# Shishir Pandey - Personal Portfolio & Blog

Welcome to the repository for my personal portfolio and blog! This site is built using [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/) for lightning-fast performance and a clean, modern aesthetic.

## 🌟 About This Site

This platform serves as my digital home where I:

- Showcase my personal projects and portfolio.
- Write blog posts about web development, technology, and life.
- Share my thoughts, experiments, and open-source contributions.

### ✨ Features

- **Ultra-fast Performance:** Powered by Astro's static site generation.
- **Responsive Design:** Looks great on desktop, tablet, and mobile.
- **Dark/Light Mode:** Full theme support with custom color palettes.
- **Integrated Music Player:** Seamless background music playback while browsing.
- **Markdown Support:** Fully featured Markdown rendering for blog posts, including code highlighting and math formulas.

## 🚀 Quick Start (Local Development)

If you'd like to clone this repository and run it locally, make sure you have `Node.js` installed.

1. **Clone the repository:**

   ```bash
   git clone https://github.com/shishir0x/blog.git
   cd blog
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

   The site will be available at `http://localhost:4321`.
