# Shishir Pandey - Personal Portfolio & Blog

Welcome to the repository for my personal portfolio and blog! This site is built using [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/) for lightning-fast performance and a clean, modern aesthetic.

## 🌟 About This Site

This platform serves as my digital home where I:

- Showcase my personal projects and portfolio.
- Write blog posts about web development, technology, and life stories.
- Share my thoughts, experiments, and open-source contributions.

### ✨ Features

- **Ultra-fast Performance:** Powered by Astro's static site generation and island architecture.
- **Responsive Design:** Fully responsive layout for desktop, tablet, and mobile.
- **Dark/Light Mode:** Full theme support with custom color palettes and system mode detection.
- **Integrated Music Player:** Seamless background audio player while browsing.
- **Markdown & MDX Support:** Fully featured rendering for posts with syntax highlighting, math formulas (KaTeX), and admonitions.
- **Pagefind Search:** Built-in fast, offline static search across all blog posts.

## 🚀 Quick Start (Local Development)

This project uses [pnpm](https://pnpm.io/) as its package manager.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18+) installed.

If you don't have `pnpm` installed globally:
```bash
npm install -g pnpm
```

### Setup & Run

1. **Clone the repository:**

   ```bash
   git clone https://github.com/shishir0x/blog.git
   cd blog
   ```

2. **Install dependencies:**

   ```bash
   pnpm install
   ```

3. **Start the development server:**

   ```bash
   pnpm dev
   ```

   The site will be available at `http://localhost:5173` (or `http://localhost:4321`).

4. **Build for production:**

   ```bash
   pnpm build
   ```

5. **Preview production build:**

   ```bash
   pnpm preview
   ```
